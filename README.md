## 📋 About

Personal portfolio of **Rajesh S**, a Full Stack and React Native Developer based in Tamil Nadu, India. It showcases real-world projects across web, mobile, and AI integration with smooth scrolling, physics-based micro-interactions, responsive design, and clean architecture.

## <a id="features"></a> ✨ Features

- **Fluid Animations**: Smooth transitions and scroll-linked micro-interactions with Framer Motion.
- **Horizontal Project Showcase**: Sticky horizontal track on desktop with spring physics and detailed project dialog modals.
- **Interactive Career Roadmap**: SVG-based animated milestone timeline tracking learning and career growth.
- **Physics-Based Hanging Profile**: Interactive physics swinging badge with drag interactions.
- **Smooth Scroll**: Native-feeling smooth scrolling powered by Lenis.
- **Responsive Layout**: Designed mobile-first, adapting seamlessly across handheld and ultra-wide displays.

## <a id="technologies"></a> 🛠️ Technologies

- **Next.js (App Router)**: Framework for performant routing, server rendering, and asset optimization.
- **TypeScript**: Complete type safety across components, content dictionaries, and hooks.
- **Tailwind CSS v4**: Modern utility-first styling with OKLCH theme color tokens.
- **Framer Motion**: Powers physics-based UI animations, page transitions, and gestures.
- **Lenis**: High-performance smooth scrolling engine with modal scroll locking.
- **Lucide React**: Clean, lightweight icons for UI navigation and project links.

## <a id="installation"></a> 🚀 Installation

Follow the steps below to run the project in your local environment:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/rajkrish63/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the Development Server:**

   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.
